Scene Torrent File Naming Conventions Explained

Scene release groups follow strict, standardized file naming conventions to convey crucial media information—such as the title, release year, resolution, source format, video/audio encoding specifications, and releasing team—directly within the folder or file name. Established by governing standard documents within "The Scene," these naming rules eliminate ambiguity, prevent duplicate releases, and allow automated systems and media managers to parse file details instantly without needing to inspect the underlying container.

Standard Release Structure

Scene release names follow a rigid, dot-delimited string that separates metadata elements into distinct tags, concluding with a hyphen and the group's identifier. The baseline syntax generally follows these templates:

  • Movies: Title.Year.[Edition/Cut].[Resolution].[Source].[Video Codec].[Audio Format]-[Group]
  • Television: Show.Name.SxxExx.[Episode.Title].[Resolution].[Source].[Video Codec].[Audio Format]-[Group]

Key Naming Components

  1. Title and Year/Episode Info:
    Spaces are replaced with periods, and special characters (such as colons, apostrophes, and slashes) are stripped or normalized. TV releases denote seasonality and episode numbers using the standard S01E01 (Season 1, Episode 1) format, or date formats (YYYY.MM.DD) for daily broadcasts.

  2. Resolution and Source Type:
    The source defines where the media was captured, while the resolution indicates output dimensions.

    • Sources: UHD.BluRay, BluRay, WEB-DL (lossless stream capture), WEBRip (re-encoded capture), HDTV, DVDRip.
    • Resolutions: 720p, 1080p, 2160p. Standard definition releases often omit resolution tags, relying solely on the source tag.

  3. Video and Audio Codecs:
    Specific encoding standards and formats are designated precisely to avoid ambiguity:

    • Video: x264 (AVC software encode), x265 (HEVC software encode), H.264/H.265 (hardware/unmodified streams), AV1.
    • Dynamic Range: HDR, HDR10+, DV (Dolby Vision).
    • Audio: AAC2.0, DD5.1 (Dolby Digital 5.1), DDP5.1 (Dolby Digital Plus), DTS-HD.MA, TrueHD.Atmos.

  4. The Release Group Suffix:
    Every scene release must end with a hyphen followed by the group's name (e.g., -SPARKS, -FLUX, -NTb). This tag acts as a digital signature representing the group responsible for ripping, encoding, and packaging the release according to scene specifications.

Real-World Examples

  • Movie Example:
    Inception.2010.2160p.UHD.BluRay.x265.TrueHD.7.1.Atmos-SWTYBLZ
    Represents the movie Inception released in 2010, sourced from a 4K UHD Blu-ray, encoded via x265 with Dolby TrueHD 7.1 Atmos audio, released by the group SWTYBLZ.

  • TV Show Example:
    Breaking.Bad.S05E16.Felina.1080p.BluRay.x264-ROVERS
    Represents Breaking Bad Season 5, Episode 16 ("Felina"), encoded in 1080p using x264 from a Blu-ray source, released by ROVERS.

Rulesets and Quality Control

Scene naming is strictly enforced by agreed-upon rule documents (such as the TV-X264 or HD-MPEG guidelines). If a group violates naming conventions, uses improper tags, or misidentifies codecs, the release is marked as "nuked" by the community, rendering it invalid for official archival and credit within the scene hierarchy.
